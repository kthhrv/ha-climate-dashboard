## Gemini Added Memories
- The project uses `pytest` for testing and has pre-commit hooks for `ruff`, `mypy`, and `prettier`.
The project is a Home Assistant custom component named `climate_dashboard`.
The `Reconciler` class in `custom_components/climate_dashboard/reconciler.py` handles hardware synchronization.
Tests are located in the `tests/` directory.
`tools/get_access_token.py` is used to generate HA access tokens for local development.
